# Multimodal Bayesian Learning for Underwater Image Enhancement

This repository contains the implementation of the **Bayesian Enhancement Model (BEM)** for underwater image enhancement, along with a **multimodal distribution-based extension**.

## Highlights

- Bayesian Neural Networks for predictive uncertainty modeling
- Variational Bayesian inference for one-to-many image mappings
- Multimodal distribution modeling for diverse plausible outputs
- Efficient BNN–DNN architecture for image refinement

## Reference

Based on:

**Bayesian Neural Networks for One-to-Many Mapping in Image Enhancement**  
Huang et al., AAAI 2026.

Original repository: https://github.com/BinCVER/BEM
